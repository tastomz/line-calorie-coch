เชื่อม / เปลี่ยนบัญชี ChatGPT
  1. บนเครื่องตัวเอง: npm i -g @openai/codex แล้ว codex login (เลือก Sign in with ChatGPT)
  2. cat ~/.codex/auth.json แล้ววางทั้งหมดในช่องด้านล่าง
  3. ระบบเข้ารหัส (AES-256-GCM) ก่อนเก็บ · ไม่แสดง token กลับมาอีก
